# User Stories (representative sample)

- As a user, I can scan my room with my camera so the AI can understand its
  layout without me typing a description.
- As a user, I can say "arrange this room using what I already have" and get
  a rearrangement plan that doesn't propose buying anything.
- As a user, I can say "don't move the TV" and have that respected as a hard
  constraint on every subsequent recommendation.
- As a user, I can set a budget ("₹40,000 for the sofa") and see running
  total/remaining as I add items.
- As a user, I can ask "why does this work?" and get a room-specific
  explanation, not a generic design platitude.
- As a user, I can see a real product's price, source, and "last checked"
  time, never a fabricated or unlabeled-stale price.
- As a user, I can view, edit, and delete my local AI memory independent of
  my cloud account.

Full story set will grow per roadmap phase; this file is updated alongside
each phase's feature work, not written speculatively in full up front.
